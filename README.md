# 概要:
スペースカンパニーは、地球上のささやかな始まりから始めて、星系間を移動し、ダイソン球を構築し、銀河全体を植民地化するSFの増分ゲームです。

開発は停止しましたが、これに基づいていくつかのプロジェクトが作成されましたので、試してみてください。
